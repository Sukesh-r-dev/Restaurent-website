# 🍽️ Savory Bites — Modern Restaurant Website

A sleek, lightweight, and fully responsive website designed for **Savory Bites Restaurant**. This repository provides an end-to-end frontend template equipped with dynamic smooth scrolling, itemized menu cards, an interactive table reservation form, and CSS Grid/Flexbox layouts.

---

## ✨ Features

- **📱 Mobile-First & Responsive Layout:** Fully optimized for desktops, tablets, and smartphones using modern CSS Grid and Flexbox.
- ** sticky Navigation Bar:** High-contrast header navigation for smooth page traversal.
- **🎨 Visual Hero Section:** Dark-overlay hero banner with direct Call-To-Action buttons.
- **🍲 Dynamic Menu Showcase:** Card-based menu presentation highlighting dishes, descriptions, and prices.
- **📅 Table Reservation Handling:** Client-side form handling for seamless reservation submissions with instant JavaScript alert feedback.
- **⚡ Lightweight & Dependency-Free:** Zero external JS frameworks or heavy UI kits required—pure HTML5, CSS3, and Vanilla JavaScript.
