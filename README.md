# Savory Bites Restaurant Website

A responsive, multi-file web application built for **Savory Bites**, featuring a modern hero section, an interactive menu, an about section, and a table reservation form.

---

## 🚀 Features

* **Responsive Navigation:** Sticky navigation bar for quick access across device sizes.
* **Featured Menu:** Grid layout showcasing popular dishes with descriptions and pricing.
* **Table Reservation Form:** Interactive booking section built with client-side JavaScript validation.
* **Clean Design:** Styled using modern CSS flexbox and grid layouts.
